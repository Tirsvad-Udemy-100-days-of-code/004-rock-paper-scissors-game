# Main

## Mulakan permainan

Dengan persekitaran maya aktif, jalankan salah satu arahan:

```bash
python -m rock_paper_scissors
```

```bash
rock-paper-scissors
```

## Peraturan

Taip `0` untuk batu, `1` untuk kertas atau `2` untuk gunting.

| Anda | Komputer | Keputusan |
| --- | --- | --- |
| Batu | Gunting | Anda menang |
| Gunting | Kertas | Anda menang |
| Kertas | Batu | Anda menang |
| Pilihan sama | Pilihan sama | Seri |

Sebarang input lain (contohnya `3` atau `rock`) mencetak mesej dan menamatkan pusingan dengan kekalahan; permainan tidak pernah ranap kerana input yang salah.

## Warna

Tajuk diwarnakan apabila output ialah terminal. Tetapkan pemboleh ubah persekitaran `NO_COLOR` untuk mematikan warna.
