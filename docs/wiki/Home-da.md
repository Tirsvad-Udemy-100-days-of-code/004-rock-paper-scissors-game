# Sten, saks, papir-spillet

Et begyndervenligt Python-program, hvor du spiller sten, saks, papir mod computeren. Det er dag 4 i Udemys *100 Days of Code™: The Complete Python Pro Bootcamp* og er bygget og dokumenteret efter rammeværket for Software Quality Assurance (SQA) og Quality Control (QC).

Du vælger `0` (sten), `1` (papir) eller `2` (saks); computeren vælger tilfældigt; begge valg tegnes som ASCII-kunst, og vinderen bliver meddelt.

## Her kan du starte

- [Installation](Install-da): opsæt Python og projektet.
- [Spil](Play-da): start spillet og læs reglerne.
- [Arkitektur](Architecture-da): hvordan koden er lagdelt og testet.
