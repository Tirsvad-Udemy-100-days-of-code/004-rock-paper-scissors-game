# Permainan Batu Gunting Kertas

Program Python yang mesra pemula untuk bermain batu, gunting, kertas menentang komputer. Ini ialah Hari 4 dalam *100 Days of Code™: The Complete Python Pro Bootcamp* daripada Udemy, dan dibina serta didokumenkan mengikut rangka kerja Software Quality Assurance (SQA) dan Quality Control (QC).

Anda memilih `0` (batu), `1` (kertas) atau `2` (gunting); komputer memilih secara rawak; kedua-dua pilihan dilukis sebagai seni ASCII dan pemenang diumumkan.
